# 小白爬虫工具 🕷️

这是一个给**零基础小白**准备的网页爬虫工具：
你只要输入一个网址，它就会自动抓取网页，分析内容，并生成一个 **Excel 表格**（.xlsx）。

## 它能做什么

- ✅ 自动抓取任意网址
- ✅ 自动识别网页类型（表格型 / 列表型 / 文章新闻型 / 普通网页）
- ✅ 自动提取网页里的表格、列表、正文段落、图片链接
- ✅ 自动处理中文乱码、尽量抓全正文
- ✅ 关键词检索：输入网址 + 关键词，找出关键词在网页里出现的所有位置（含命中片段）
- ✅ 多页爬取：可选爬取页数，顺着「下一页」继续抓（防止数据过多、等待过久）
- ✅ 对抗反爬：像真人浏览器的请求头 + 会话 Cookie + 失败重试 + 礼貌延时
- ✅ 动态渲染：可选 Selenium 驱动 Edge，抓取 JS 动态加载的内容
- ✅ 自动生成 Excel 表格，数据分多个工作表存放
- ✅ 有图形界面：双击就能用，不用碰命令行
- ✅ 可打包成单个 exe，发给别人直接双击使用

## 文件夹里都有什么

| 文件/文件夹 | 作用 |
|------|------|
| `dist/小白爬虫.exe` | **打包好的成品软件，双击即用（发给别人就用这个）** |
| `启动爬虫.bat` | 在"有 Python 的电脑"上双击打开图形界面 |
| `gui.py` | 图形界面程序（窗口版） |
| `main.py` | 命令行版入口（在黑色窗口里输入网址） |
| `crawler.py` | 爬虫核心，负责抓取网页 + 自动分析 |
| `exporter.py` | 负责把数据生成 Excel 文件 |
| `requirements.txt` | 需要安装的第三方库清单 |
| `SpiderTool.spec` | PyInstaller 的打包配置文件（重新打包时用） |
| `output/` | 程序自动创建，生成的 Excel 都会放在这里 |

## 怎么使用（分两种情况）

### 情况一：直接把 exe 发给别人（对方电脑不需要装 Python）

把 `dist/小白爬虫.exe` 这一个文件发给对方，对方双击就能用。

> ⚠️ 注意：因为没花钱做"代码签名"，对方第一次双击时，Windows 可能会弹出
> 「Windows 已保护你的电脑」的蓝色警告。让对方点 **「更多信息」→「仍要运行」** 即可。
> 个别杀毒软件也可能误报，添加信任即可（这是 PyInstaller 打包程序的常见现象，不是病毒）。

### 情况二：在你自己的电脑上用（已装 Python）

- 先装依赖（一次性）：`pip install -r requirements.txt`
- 双击 `启动爬虫.bat`，或运行 `python gui.py`

## 图形界面怎么操作

双击打开后，照着窗口里的说明做：

1. 在网址输入框粘贴或输入网址（可以省略 `https://`）
2. 可选：填关键词、选爬取页数、勾选「动态渲染」
3. 点「开始爬取」
4. 等几秒，自动生成 Excel
5. 点「打开结果文件夹」查看生成的表格

几个选项的意思：

- **关键词**：填了就在网页里检索它出现在哪些地方，不填就只爬取不检索。
- **爬取页数**：填 1 只爬当前页；填 N 会顺着网页里的「下一页」链接继续爬，最多爬 N 页（找不到下一页会提前停）。
- **动态渲染**：勾选后用 Selenium 驱动 Edge 浏览器，把 JS 动态加载的内容也抓下来。第一次使用前需先运行 `pip install selenium`。

## 生成的 Excel 长什么样

生成的 Excel 在 `output/` 文件夹里，文件名类似：
`20261028_153045_www.baidu.com.xlsx`

里面会按网页里有什么内容，自动生成这些工作表：

- **网页信息**：网址、标题、网页类型、爬取页数、描述
- **表格1 / 表格2 / ...**：网页里的每个表格各占一个工作表
- **列表数据**：网页里的列表条目
- **正文段落**：网页正文的段落
- **图片链接**：网页里的图片网址
- **关键词检索**：填了关键词才有；含关键词、总出现次数，以及每条命中的「所在区域 + 命中片段」

## 重新打包成 exe（改代码后想重新生成）

如果你以后改了 `gui.py` / `crawler.py` 等代码，想重新打包，在命令行里依次运行：

```
python -m venv build_venv
build_venv\Scripts\python.exe -m pip install requests beautifulsoup4 lxml openpyxl pyinstaller
build_venv\Scripts\python.exe -m PyInstaller --onefile --windowed --noconfirm --clean --name SpiderTool gui.py
```

打包完成后，新的 exe 在 `dist\SpiderTool.exe`（可自己改名成中文）。

## 常见问题

- **双击 exe 弹出 SmartScreen 警告**：正常现象，点「更多信息」→「仍要运行」。
- **双击 `启动爬虫.bat` 没反应**：多半是没装 Python，或没勾选 "Add Python to PATH"。
- **爬取失败 / 报错**：先检查网址有没有写错、能不能上网。有些网站会拒绝爬虫访问，这是正常现象。
- **中文乱码**：程序里已经做了编码处理，一般不会乱码。
- **内容抓不全**：有些网站（比如小红书、淘宝、微博这类）的正文是用 JavaScript 动态加载出来的，普通爬虫抓不到。这类网站需要更重的「浏览器自动化」方案（如 Selenium/Playwright），可以以后再单独加。
- **想要爬某个特定网站（比如某电商）**：当前版本是"通用版"，对复杂网站可能抓不全；如果需要，可以再做针对性的定制版。

> 提醒：爬虫要遵守网站的 robots 协议和相关法律法规，只抓取公开、允许访问的内容，不要用于商业滥用或高频攻击。
